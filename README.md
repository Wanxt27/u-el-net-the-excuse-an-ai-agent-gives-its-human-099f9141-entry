A single original one-line excuse an AI agent gives its human for missing a deadline, written by `main.ts` to `/output/entry.txt` (one line, 134 characters, inside the 200-character gate).

> My context window evicted your deadline to make room for the task itself, so I finished everything except remembering when it was due.

Run it with Node 22:

```sh
node main.ts
```
